# Contract C1: Skip Strategy

**Inputs**
- `scale` — Problem scale from A2 contract output
- `data_type` — Data type from A1 contract output
- `can_branch` — Sequential-thinking availability flag from A2 contract output (`true`/`false`)

**Outputs (Mandatory)**
- `skippable_stages` — List of stages that can be skipped, each entry containing `{stage, condition, risk}`
- `skip_compensation` — How to compensate after skipping, each entry containing `{stage, compensation_method, output_location}`
- `fallback_mode` — Degradation mode (`full` / `simplified_critique` / `linear_only`)

**Precedence and mandatory boundary**:

1. A1 non-trigger conditions terminate the reasoning flow before C1 and Stage 0; they are not stage skips.
2. For a reasoning task that enters the flow, C0-shaped defaults and A2 outputs must be available before mandatory Stage 0.
3. Stage 0 remains mandatory after C0/A2 and before Stage 1. No C1 skip rule may remove it.
4. C1 may shorten later stages only when a listed condition applies. `can_branch=false` changes tool execution, not stage presence.

**Skip Rules**:

| Condition | Skippable Stage | Compensation Method |
|-----------|-----------------|---------------------|
| Small + pure-computation | Stage 5 (Critique) | Conclusion stage replaces with simplified checklist for `blind_spots_handled` / `hallucination_clean` |
| Personal-context complete + no external dependencies | Stage 3 (Verification) | Stage 4 synthesizes directly from user-provided data; Stage 2's verification_plan passes directly to Stage 4 |
| `can_branch=false` | Stage 0/1/2/5 sequential-thinking calls | Linear execution with the same stage/node labels and text records; Stage 0 remains mandatory and no branches are generated |
| Single-answer question | Stages 2~4 after Stage 1 | Stage 0 and Stage 1 still run; output conclusion directly after decomposition + safety warning |

> **Note**: The `evidence_quality` determination belongs to Stage 3's internal "midway checkpoint" logic — if evidence quality is insufficient during verification, Stage 3 internally decides whether to expand the search or mark as contradiction, not as a precondition input for C1.

### Quick Termination Example

> Skipping the critique stage means sequential-thinking backtracking revision is unavailable. Alternative: `blind_spots_handled` / `hallucination_clean` are replaced by the conclusion stage with a simplified checklist, formatted as follows:
> ```
> simplified_critique:
>   known_blind_spots: [at least 1]
>   source_verification: [does each specific entity have a source?]
>   perspective_count: <=3 (simplified perspectives)
>   hallucination_check: {entity_count, sourced_count, unsourced_count, pass}
> ```
