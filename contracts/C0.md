# Contract C0: User Context Capture

**Trigger conditions**: Auto-triggered for `decision` / `daily` / `career` domains; optional for other domains.

**Inputs**
- `raw_question` — User's original question
- `primary_domain` — Primary domain from A1 contract output
- `data_type` — Data type from A1 contract output

**Outputs (Mandatory)**
- `user_constraints` — Structured user constraints, each entry containing `{type, value, mandatory}`
  - `type` — Constraint type (`budget` / `location` / `time` / `priority` / `skill_level` / `other`)
  - `value` — Constraint value
  - `mandatory` — Whether hard constraint (yes/no)
- `implicit_assumptions` — List of implicit assumptions inferred from the question, each entry containing `{assumption, source}`
  - `source` — Inference source (`question_text` / `domain_knowledge` / `common_sense`)
- `success_criteria` — Success criteria, each entry containing `{criterion, measurable, threshold}`

**Outputs (Optional)**
- `clarification_needed` — List of questions needing clarification from the user (if constraints are insufficient for reasoning)
