# Contract A4: Source Quality Tiers

**Defines the quality level of each evidence source, ensuring different quality sources have different weights.**

---

## Source Tier Definitions

| Tier | Name | Weight | Type | Specific Examples |
|------|------|--------|------|-------------------|
| **T1** | Independent Media / Official | 100% | Independent investigative reporting, official announcements, government records | Regional investigative/watchdog journalism, brand official channels, business registry records (Crunchbase / OpenCorporates) |
| **T2** | Consumer Media / Review Platform | 70% | Consumer media reports, consumer review platforms | Yahoo Travel, TripAdvisor, Yelp / Google Reviews, Reddit / verified community posts |
| **T3** | KOL / Paid Promotion | 30% | KOL videos/posts, paid sponsored content, sponsored content | YouTube paid promotion videos (labeled "Includes paid promotion"), Instagram sponsored posts, SEO marketing articles |
| **T4** | Community Discussion / Forum | 50% | Community discussions, forum posts | Reddit, general forums, Quora (cross-verification needed), Facebook groups |
| **T5** | Merchant Self-Claim | 20% | Merchant official social pages, promotional posters, in-store notices | Facebook page, merchant promotional poster, in-store price list |

---

## Marketing Content Detection Rules (P0)

**When all sources are T3, mark as "source untrustworthy."**

Marketing content characteristics (meet >= 3 items to be considered marketing content):

```
[ ] Exaggerated adjectives: "game changer", "best-in-class", "unbeatable", "the GOAT", "revolutionary", "number one", "world's thinnest/lightest"
[ ] Multiple similar articles using the same keyword combinations
[ ] No specific experience details: lacks first-person descriptions like "I went to", "I used"
[ ] Contains purchase links or booking buttons
[ ] Source websites belong to the same content marketing network (multiple different domains but same writing style / same author group)
[ ] Video labeled "Includes paid promotion" or merchant-sponsored commercial collaboration
```

**Judgment Results**:
- All recommended sources are marketing content -> `source untrustworthy`, requires additional independent sources
- Partially marketing content + partially independent sources -> `partially credible`, prioritize independent source data
- No marketing content characteristics -> `credible`

## Cross-Source Verification Rules

### Type A Claims (Objective Fact)

```
[ ] At least 1 T1 or T2 source
    -> or
[ ] At least 2 T3/T4/T5 sources with consistent content
    -> but T3 source numbers must be marked "not independently verified"
[ ] If all sources are T3 -> mark "verification failed", need to find T1/T2 sources
[ ] If source tier disparity is large (T1 says X, T5 says Y) -> use T1 as authoritative, note contradiction
```

### Type B/C Claims (Quality Assessment / Channel Relationship)

```
[ ] Mark highest and lowest source tier
[ ] If highest tier is T3 -> mark "KOL promotion only, lacks independent verification"
[ ] If highest tier is T4 (community discussion) -> mark "community word of mouth, requires cross-verification"
[ ] Channel relationship (Type C): at least 2 different paths (see A3 contract)
```

### Type D Claims (Promotional/Quote)

```
[ ] All Type D claims must be labeled with:
    - Source tier (T1-T5)
    - Publication date
    - Whether it is a promotional/limited-time offer
    - "Not independently verified" (if source is T3)
[ ] Prohibit citing promotional prices as regular prices
[ ] In the final output, Type D claims must include "actual prices are subject to store quotations"
```

### Type E Claims (Speculation)

```
[ ] Mark as "speculative"
[ ] Mark the source tier of the basis for speculation
[ ] Must not be mixed in the same table as Type A/B/C/D facts
```

---

## Source Labeling Format

Every piece of evidence must include a source label:

```
{
  claim: "specific claim",
  source_url: "https://...",
  source_tier: "T1/T2/T3/T4/T5",
  source_type: "independent media/KOL/merchant self-claim/...",
  is_paid_promotion: true/false,
  date: "2026-08-12",
  marketing_indicators: ["exaggerated adjectives", "contains purchase link"],
  verification_status: "passed/partial/failed"
}
```
