# Contract A3: Claim Type Definitions

**Defines the verification threshold for each claim type, ensuring different types of facts are verified with different levels of rigor.**

---

## Claim Types

| Type | Name | Description | Verification Threshold | Examples |
|------|------|-------------|------------------------|----------|
| **A** | Objective Fact | Specific information independently verifiable | >= 2 independent sources (at least 1 T1/T2) or >= 2 consistent T3/T4/T5 sources (marked `not independently verified`); single-source or all-T3 = `verification failed` | Address, phone number, price, year founded, official authorization status |
| **B** | Quality Assessment | Subjective judgment or consumer experience | >= 1 independent media + >= 3 consumer reviews | Reputation, service quality, comfort of wear |
| **C** | Channel Relationship | Business relationship between two entities | >= 2 different paths find evidence of relationship | Store A sells Brand B's products, Brand C's distributor in a city |
| **D** | Promotional/Quote | Temporary or promotional price information | Mark source and time, must confirm with store/official | "72% off" "From $28" "Limited time offer" |
| **E** | Speculation/Inference | Evidence-based inference, not direct observation | Clearly mark "speculative", do not cite as fact | Brand positioning inference, market share estimation, trend prediction |

---

## Verification Rules

### Type A (Objective Fact)

```
[ ] At least 2 independent sources confirm (at least 1 T1/T2; or >=2 consistent T3/T4/T5 marked `not independently verified`)
    -> Independent source definition: different websites, different authors, different organizations
    -> If multiple sources are actually the same marketing campaign (same writing style, same keyword stacking, same website group) -> treat as single source
[ ] If 2 sources differ by >20% -> mark "significant contradiction", requires additional source arbitration
[ ] Single source -> mark "verification failed", cannot be cited as fact
[ ] Checkable on maps (Google Maps / OpenStreetMap)
[ ] Checkable on business registry (Crunchbase / OpenCorporates / official business registry)
```

### Type B (Quality Assessment)

```
[ ] At least 1 independent media report
[ ] At least 3 consumer reviews (genuine reviews, not marketing content)
[ ] If only marketing content -> mark "review untrustworthy"
[ ] If review source is single (one platform only) -> mark "partially credible"
```

### Type C (Channel Relationship)

```
[ ] At least 2 different paths find evidence of the relationship:
  Path 1: Brand name + city -> official authorized store list
  Path 2: Store name + brand name -> products actually sold at the store
  Path 3: Distributor name + brand -> distributor product catalog
  Path 4: Product line name + city -> distribution network for specific model
[ ] Only Path 1 has results -> mark "official channel confirmed, non-official channels unknown"
[ ] Only Paths 2/3/4 have results -> mark "non-official channel confirmed, official authorization status unknown"
[ ] All 4 paths return zero -> mark "channel relationship unverified"
```

### Type D (Promotional/Quote)

```
[ ] Mark source name and publication date
[ ] If source is T3 (KOL/paid promotion) -> additionally mark "not independently verified"
[ ] If offer has an expiration date -> mark expiration date, must re-quote after expiry
[ ] In the final output, all Type D claims must include a disclaimer: "actual prices are subject to store quotations"
[ ] Prohibit citing promotional prices as regular prices
```

### Type E (Speculation/Inference)

```
[ ] Must clearly mark "speculative" or "inference"
[ ] Must state the basis of the inference
[ ] Must not be mixed in the same table as Type A/B/C/D facts
[ ] In the final output, speculative content must be presented separately from verified facts
```

---

## Mandatory Registration Rule

**Before the verification stage begins**, the claim registry must be completed:

```
claim_registry = [
  {
    claim: "specific claim content",
    type: "A/B/C/D/E",
    verification_threshold: "corresponding threshold",
    sources_found: [],
    verification_status: "failed/partial/passed",
    notes: "special notes"
  }
]
```

**Unregistered claims must not enter the final conclusion.**

- **C2 Contract**: `claim_registry` passes from Stage 2 to Stage 3; `claim_verification_status` passes from Stage 3 to Stage 4
