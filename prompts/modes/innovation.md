# Innovation: Lateral Thinking

**Core Mechanism**: Break Assumptions -> Recombine Elements -> New Combinations

**Applicability**: Breaking through bottlenecks, new feature ideation, non-traditional solutions

**Integration with Stages**:

| Stage | Mode Impact |
|-------|-------------|
| Stage 1 Decomposition | First list implicit assumptions, then ask "what if this assumption is false?" |
| Stage 2 Hypothesis | At least 1 "counter-intuitive hypothesis"; null hypothesis is "existing solution is sufficient" |
| Stage 3 Verification | Relax verification standards for counter-intuitive hypotheses: feasibility > optimality; first confirm "it works" rather than "it's best" |
| Stage 4 Synthesis | Hybrid strategy of new combination + existing solution; do not pursue pure innovation |
| Stage 5 Critique | Required "Assumption Challenge" as the core perspective: were the right assumptions broken? "Execution Feasibility": can the innovation be implemented? |
| Stage 6 Conclusion | Innovation proposal + feasibility assessment + minimum steps to validate MVP |

**Output Characteristics**: List of broken assumptions + New combination proposal + MVP path
