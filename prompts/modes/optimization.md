# Optimization: Gradient-Descent Thinking

**Core Mechanism**: Current State -> Gradient Direction -> Step Size -> Convergence Check

**Applicability**: Performance optimization, cost optimization, process optimization, parameter tuning

**Integration with Stages**:

| Stage | Mode Impact |
|-------|-------------|
| Stage 1 Decomposition | Decompose by metrics: establish baseline + bottleneck dimensions + target values |
| Stage 2 Hypothesis | Each bottleneck's optimization direction is a hypothesis; null hypothesis is "current state is already optimal" |
| Stage 3 Verification | Quantitative verification: A/B test data, benchmark comparison, ROI calculation |
| Stage 4 Synthesis | Evaluate diminishing returns point; determine if local optimum has been reached |
| Stage 5 Critique | Required "Time" perspective: decay curve after optimization; "Risk" perspective: is the optimization trade-off acceptable? |
| Stage 6 Conclusion | Pre- vs post-optimization comparison + iteration plan + stop conditions |

**Output Characteristics**: Baseline -> Post-optimization comparison + Marginal return curve + Iteration path
