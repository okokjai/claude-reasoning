# Decision: Decision Matrix

**Core Mechanism**: Options x Criteria -> Weighted Scoring -> Sensitivity Analysis

**Applicability**: Technology selection, vendor selection, priority ranking, solution decision-making

**Integration with Stages**:

| Stage | Mode Impact |
|-------|-------------|
| Stage 1 Decomposition | Decompose into: option list / evaluation criteria / weights / constraints |
| Stage 2 Hypothesis | Each option is a hypothesis; null hypothesis is "maintain status quo" |
| Stage 3 Verification | Verify each option's actual performance data, not just theoretical specifications |
| Stage 4 Synthesis | Weighted scoring matrix + sensitivity analysis (vary weights +/-20% to see ranking changes) |
| Stage 5 Critique | Required "Contrarian" perspective: reasons for the worst option; "Non-Quantitative Factors": soft factors that weights cannot capture |
| Stage 6 Conclusion | Recommendation + worst-case analysis + exit conditions |

**Output Characteristics**: Scoring matrix table + Sensitivity analysis + Worst-case assessment
